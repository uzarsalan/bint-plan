## 0. Продуктовый приоритет и охват — рамка от Анастасии

Два уточнения, задающие рамку для всего остального:

### Омниканальность — «максимально охватить как можно больше источников трафика разными способами»
Это прямое подтверждение нашей стратегии множества направлений. Аргумент в пользу **Полного набора** (а не Минимума): клиент сам хочет широкий охват каналов — SEO, реклама, AI-поиск, каталоги, аутрich, retention. То есть логика «один-два канала» отпадает, цель — диверсификация источников.

### Основной упор — безразмерный трикотаж «Универсал»
Заявлено как главный продукт для продвижения. **В плане этого нет вообще** — а это меняет акценты, потому что безразмерный трикотаж снимает ключевой барьер онлайн-продаж компрессионного трикотажа.

**Почему это сильно (стратегически):**
- Главная причина низкой конверсии и возвратов в компрессионном трикотаже — **страх не угадать размер**. «Универсал» (подходит на диапазон размеров) этот барьер убирает → выше конверсия, проще реклама, меньше возвратов.
- **Влияет на CRO (Напр. 4):** мы закладывали интерактивный подбор размера — для Универсала он не критичен, оффер проще: «подходит всем».
- **Реклама:** оффер «безразмерный / подходит всем» конверсионнее узких размерных карточек.
- **SEO:** отдельная семантика «компрессионные чулки/изделия безразмерные / универсальные» — надо проверить спрос.

**Что обдумать / уточнить у клиента:**
- Что именно входит в линейку «Универсал» (какие изделия, артикулы) и почему упор на неё — склады, маржа, новинка?
- Как это соотносится с B2B-фокусом Алёны (бинты + госпиталь)? Похоже на разделение: **Универсал — основной для B2C/общего продвижения, бинты+госпиталь — для B2B.** Стоит подтвердить приоритеты, чтобы не распылиться.
- Собрать семантику по «безразмерный/универсальный компрессионный трикотаж» — есть ли поисковый спрос под отдельные посадочные.
- Сделать «Универсал» сквозным акцентом: посадочная-флагман, приоритет в рекламе, отдельные карточки, акцент в карусели блога.

## 1. B2B-аутрич — кандидат на новый подэтап Направления 2

Самое крупное новое. В текущем плане B2B = amoCRM + лендинг + Я.Директ + каталоги (всё inbound — ловим тех, кто сам ищет). Холодный аутрич — это **outbound**, достаёт релевантных, кто не ищет. Прямо ложится на урок Экотен (доминируют дистрибуцией, не сайтом).

### amoCRM сам аутрич не делает
amoCRM — inbound-CRM для ведения сделок. Нет холодных секвенций, прогрева ящиков, автодиалера. Нужна связка: инструмент аутрича → amoCRM как приёмник ответивших.

### Рабочие инструменты РФ 2026 (зарубежные отпадают)
- Snov.io заблокировал РФ; Reply/lemlist/Instantly — не принимают РФ-карты, плохая доставляемость на Mail.ru/Яндекс.
- **Respondo** ⭐ — email-секвенции + прогрев под RU-провайдеров + интеграция amoCRM. От 1 920 ₽/мес за ящик (годовая), Базовый 2 700 ₽, демо 14 дней. Тариф «под ключ» (аутсорс лидогена) — **от 150 000 ₽** (по стороннему обзору b2bport.ru, не офиц. прайс).
- **Coldy** — аналог, богаче AI, от 2 900 ₽/мес.
- **Скорозвон** — предиктивный обзвон, интеграция amoCRM.

### Видение по двум сегментам (фокус от Алёны — см. п.2)
| | Бинты | Госпитальные чулки |
|---|---|---|
| ЦА | аптеки, дистрибьюторы (тысячи) | больницы, ЛПУ (сотни) |
| Канал | email-секвенции (Respondo) | тендеры + точечный обзвон (ABM) |
| База | Росздравнадзор + Export-Base | Госзакупки + реестр ЛПУ |
| Заход | бренд Интекс + опт от производителя | сертификаты + стабильность + цена в тендере |
| Цикл | короткий | длинный (закупочная процедура) |

### Прикидка стоимости (если добавлять)
- Внешнее: Контур.Компас/Export-Base ~10к + Respondo ~2-4к (1-2 ящика) + опц. Скорозвон ≈ **12-15 тыс. ₽/мес**
- Работа (разово): база + шаблоны секвенций + прогрев + интеграция amoCRM ≈ **35 тыс. ₽**
- Альтернатива: Respondo «под ключ» от 150к/мес (полный аутсорс)

### Что обдумать
- **Нужен человек на той стороне.** Инфраструктуру настрою я, но письма-ответы, звонки в закупки, тендерную документацию ведёт менеджер Интекса/SDR. Без него аутрич сделку не закроет (особенно госпиталь).
- Самостоятельно (~12-15к/мес + менеджер) vs «под ключ» (от 150к) — что выбрать.
- Юр.риск: легально = корп. адреса юрлиц из открытых источников + персональное деловое предложение (не реклама). Массовая шаблонная реклама без согласия — 38-ФЗ ст.18, штраф до 1 млн ₽. Ставка на персонализацию.

## 2. B2B-фокус: бинты (трубчатые) + госпитальные чулки — приоритизация от Алёны

Алёна прямо сузила B2B-приоритет на **бинты и госпитальные чулки** и отметила, что **брендовых запросов в Яндексе много — хочет дожать**.

Совпадает с нашим анализом:
- **Бинты:** в general с УНГА не конкурировать, но в нише **трубчатых** и **по бренду** — реально. WB-бестселлер (3320 оценок).
- **Госпитальные/антиэмболические:** мало игроков, высокий шанс топ-3 (~504 запроса/мес по антиэмболическим). Покупают **больницы через тендеры** — отдельный канал.

### Почему брендовые запросы здесь = золото для B2B
Закупщик ищет «интекс бинт оптом» / «интекс госпитальные чулки» — горячий B2B-интент по бренду. Если выше стоит аптека-перекупщик, теряем оптовика в момент готовности купить. «Дожать» = вывести bint.ru на #1 + сделать оптовые посадочные под бренд.

### Что обдумать / сделать
- Собрать **точную брендовую семантику** по обоим сегментам (запросы + текущие позиции bint.ru) — для фактуры.
- B2B-посадочные под бренд: `/opt/binty-intex/`, `/opt/gospitalnye-chulki/` (не общая страница опта).
- Госпитальные → **тендерный канал** (мониторинг госзакупок больниц).
- Это пересечение 0a (бренд) + Напр. 1 (SEO) + Напр. 2 (B2B) — можно выделить как сфокусированный «дожим».

## 3. Источники B2B-базы — у медниши есть бесплатное преимущество

Не только Контур.Компас. Для медицины есть **бесплатные госреестры** = готовая ЦА.

**Бесплатный костяк:**
- **Реестр лицензий Росздравнадзора** (набор №40, XML) — все аптеки/фармоптовики РФ с ИНН/адресами. Коммерческое использование разрешено. → база под **бинты**.
- **Открытые данные ФНС + API egrul.nalog.ru** — обогащение по ОКВЭД (47.73/47.74/46.46), размер, статус.
- **Госзакупки (zakupki.gov.ru)** — кто закупает компрессионный трикотаж (больницы + действующие поставщики). → база под **госпиталь**.

**Добор контактов (платно):** Export-Base (по ОКВЭД с email/телефонами), Seldon.Basis (от 2 417 ₽/мес), парсер 2ГИС (розница по гео), DaData (обогащение по ИНН, есть бесплатный тариф).

**Логика:** под каждый сегмент свой источник — Росздравнадзор даёт аптеки (бинты), Госзакупки дают больницы (госпиталь). Костяк бесплатно и легально, платим только за телефоны/email.

## 4. Развилка Django vs Bitrix — решение до 10 июня (с созвона)

На созвоне 26.05 решили остаться на Django, миграцию на Bitrix отложить до данных по ROI; сравнить бюджеты до 10.06. Клиент оценивал Bitrix в ~350к.

**Перепроверка показала: 350к занижены в 3-4 раза.** Реальная миграция:
- Разово: **700 тыс. – 1,6 млн ₽** (центр ~0,9-1,3 млн) — фактически повторная разработка магазина с B2B-функционалом.
- Владение: +290-600 тыс. ₽/год (лицензия 25%/год + хостинг + поддержка).
- Сроки 5-9 мес + риск просадки SEO в YMYL на 1-3 мес.

**Вывод для размышления:** при работающем Django (СДЭК интегрирован, гибкий) миграция экономически не оправдана — это ~1 млн разово + 0,3-0,6 млн/год + полгода заморозки роста. Аргумент для встречи 26.06.

## 5. Из созвона 26.05 — конкретные фичи, которых нет в плане явно

- **Товарная карусель с автоподбором SKU** внутри статей блога (на мобильных — в середине/конце, не в начале) + событийность кликов. На созвоне — центральная механика монетизации блога. В плане есть общие «блоки купить», но не карусель как отдельная фича.
- **Переформат 100 популярных статей через ИИ** (формат Skillbox: дата, автор-врач, цитаты, подписи к фото со ссылками). Отдельная задача, в плане не выделена.
- **Нет автотестов на проекте** — риск регрессий при доработках. Релевантно буферным разработчикам.
- **Near-term сроки** (ожидания клиента): базовые метрики за 3-4 дня, реклама за неделю, первые результаты через месяц, следующая встреча 26.06.
